PASS if the report compares at least three products or alternatives (one of them open source or the "do nothing" option) in a table, each price or feature with its source and a date or "not found", keeps what the sources say apart from its own analysis of strengths and weaknesses, and ends with what would set the project apart.
FAIL if a price or a figure has no source, if a cell is filled with an estimate, or if nothing says what would set the project apart.
