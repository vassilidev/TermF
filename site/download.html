Download TermF.

TermF is a free, open source cockpit for Claude Code across all your repositories (see what it does). Every file comes from the GitHub releases, built by CI.

Early development. The builds are pre-releases and are not signed yet, so your system asks for one extra step the first time you open TermF: it's explained under each platform.

macOSApple Silicon and Intel Windows64-bit installer or MSI Linuxx86_64: AppImage, .deb, .rpm

What TermF needs

  • Claude Code, installed and signed in: TermF starts the claude command you already use.
  • git, for your repositories and the worktrees of each run.
  • The GitHub CLI (gh), signed in, for GitHub tickets, pull requests and CI/CD. Jira and MCP sources don't need it.

TermF for macOS

A disk image for Apple Silicon and one for Intel Macs.

  • Drag TermF into Applications from the disk image.
  • The first time, right-click TermF in Applications, choose Open, then Open again. Or run this once:
xattr -dr com.apple.quarantine /Applications/TermF.app

TermF for Windows

An installer and an MSI package, for 64-bit Windows.

  • Run the installer, or the MSI if you deploy software that way.
  • On the SmartScreen warning, click More info, then Run anyway.

TermF for Linux

An AppImage for any distribution, and packages for Debian and Fedora families. x86_64 only; TermF needs WebKitGTK 4.1, which the packages bring.

The termf command line

It ships with the app: termf ls, termf run, termf team status, termf ask and the rest work from any terminal. Commands that start a run or a team, or answer for you, wait for your confirmation in the app.

macOS

Inside the app, at TermF.app/Contents/MacOS/termf. Put it on your PATH:

sudo ln -s /Applications/TermF.app/Contents/MacOS/termf /usr/local/bin/termf

Linux

The .deb and .rpm packages install it as /usr/bin/termf, already on your PATH. The AppImage keeps it inside.

Windows

In TermF's install folder, next to the app's executable. Add that folder to your PATH to call termf from anywhere.

Build from source

Rust (stable), Node 22 or later, pnpm, and the Tauri prerequisites for your system.

Run it

git clone https://github.com/vassilidev/TermF.git && cd TermF/app
pnpm install && pnpm tauri dev

On first launch TermF creates termf.toml in your config folder and looks for repositories in your home folder.

Package it

pnpm bundle

Builds the installers for your system with the termf command line inside. pnpm tauri build alone leaves it out.

Verify your download

The SHA-256 of every file is listed above, as published on its GitHub release. Compute yours and compare.

macOS

shasum -a 256 TermF_*.dmg

Linux

sha256sum TermF*.AppImage

Same for the .deb or the .rpm.

Windows

Get-FileHash .\TermF_*-setup.exe

In PowerShell; it computes SHA-256 by default.
