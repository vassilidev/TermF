        Install

        The builds are not signed yet, so the first launch asks for one extra step.

        macOS

        1. Open the .dmg and drag TermF to Applications.
        2. Clear the quarantine once, in a terminal:
        xattr -dr com.apple.quarantine /Applications/TermF.app

        Or right-click the app, Open, then Open again.

        Windows

        1. Run TermF_*_x64-setup.exe, or the .msi.
        2. On the SmartScreen warning, click More info, then Run anyway.

        Linux

        The termf command line

        It ships with the app, there is nothing else to install. Put it on your PATH, then termf help lists every command. Commands that start a run or a team, deliver, approve a gate or type into a session wait for your confirmation in the app.

        What the command line does

        macOS

        sudo ln -s /Applications/TermF.app/Contents/MacOS/termf /usr/local/bin/termf

        Linux

        The .deb and .rpm install it as /usr/bin/termf.

        Windows

        termf.exe sits next to the app: add its folder to your PATH.

        Check a download

        Compare the file's SHA-256 with the one listed above, which GitHub computes for each file of the release.

        macOS

        shasum -a 256 TermF_*_aarch64.dmg

        Linux

        sha256sum TermF_*_amd64.AppImage

        Windows

        Get-FileHash .\TermF_*_x64-setup.exe -Algorithm SHA256

        Build it from source

        You need Rust (stable), Node 22 or later, pnpm and the Tauri prerequisites for your system. pnpm bundle builds the installers for your system with the command line inside.

        git clone https://github.com/vassilidev/TermF.git
        cd TermF/app && pnpm install
        pnpm tauri dev
